
# Introduction to Data Science Lab

## 📘 About the Subject
Introduction to Data Science Lab focuses on understanding the fundamental concepts of data science through practical implementation using Python. It covers data handling, preprocessing, statistical analysis, data visualization, and basic machine learning techniques.

## 🎯 Objectives
- Understand the fundamentals of Data Science.
- Perform data manipulation and analysis using Python.
- Learn data visualization using Matplotlib and Seaborn.
- Apply statistical techniques to datasets.
- Perform data preprocessing and exploratory data analysis (EDA).
- Implement basic machine learning algorithms.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Platform:** Google Colab / Jupyter Notebook
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn
